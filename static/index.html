How LumaFusionNet works

The proposed model combines information from the image's spatial structure and its frequency representation, then learns to reconstruct a clearer image.

01

Low-light RGB input

The uploaded image is decoded and converted into the tensor format expected by the model. Its original spatial layout is retained so local details can be recovered.

02

Parallel spatial and frequency feature extraction

Spatial branch: learns local patterns such as edges, textures, objects and neighbouring-pixel relationships. Frequency branch: uses a Fourier transform to represent image structure in the frequency domain, separating amplitude information from phase information. These complementary cues can help represent illumination changes and fine structures.

03

Feature fusion

Features from both branches are combined into a shared representation. The aim is to retain useful spatial detail while incorporating global frequency-domain structure.

04

Encoder, attention and decoder

The encoder progressively extracts higher-level features at multiple scales. A channel-attention block can emphasise informative feature maps. The decoder upsamples the representation, while skip connections carry finer encoder details forward to help preserve structure.

05

Residual reconstruction

The reconstruction stage predicts an image correction that is combined with the input through a residual pathway. The result is converted back into an RGB image for display and download.

Inference path

Browser upload → FastAPI endpoint → image preprocessing → model or demo fallback → PNG response → browser preview/download.
